## 2. Example with Animation

You can enable animation and control it from the parent component using two callback properties:

- `onStart`: Called when the animation starts
- `onComplete`: Called when the animation completes

```tsx
<AnimatedConnection
  source={sourceRef}
  target={targetRef}
  onStart={() => console.log('Animation started')}
  onComplete={() => console.log('Animation completed')}
/>
```

\<AnimatedConnection
  source={sourceRef}
  target={targetRef}
  onStart={() =\> console.log('Animation started')}
  onComplete={() =\> console.log('Animation completed')}
\</AnimatedConnection>

# Release Notes - Version 12.0.0

## Overview

Version 12.0.0 introduces a simplified test API with endpoints for account management, transactions, and fraud reporting.

## New APIs

### Accounts

- Create Account
- Update Account
- Delete Account

### Transactions

- Create Transaction
- Get Transaction

### Fraud

- Report Fraud
- Refund Transaction

## Notes

This version is intended for testing and demonstration purposes. API behavior, request fields, and response formats may change in future releases.

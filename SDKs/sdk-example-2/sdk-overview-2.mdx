# Developer Studio Test SDK 2

> Developer Studio Test SDK 2 is an example of file structure and documentation that tenants can use when setting up the documentation for their SDKs. This example is not based on real-world software and is only presented to inform tenants about the SDK functionality now part of the Developer Studio ecosystem.

## Overview

The Developer Studio Test SDK 2 enables developers to connect to the analytics engine, execute queries against large datasets, and stream results efficiently. It abstracts connection pooling, authentication, and result pagination so you can focus on data logic.

## Architecture

The SDK communicates with the Query Service over gRPC for streaming operations and REST for management operations.

```
┌─────────────┐       ┌──────────────────┐       ┌─────────────────┐
│ Your App    │──────▶│  Developer Studio Test SDK 2   │──────▶│ Query      │
│ (Java/Py)   │       │  (gRPC + REST)   │       │ Service         │
└─────────────┘       └──────────────────┘       └─────────────────┘
                              │
                              ▼
                      ┌──────────────────┐
                      │ Connection Pool  │
                      │ & Auth Manager   │
                      └──────────────────┘
```

## Authentication Methods

| Method | Use Case | Configuration |
| ------ | -------- | ------------- |
| API Key | Server-to-server applications | Set `apiKey` in client config |
| OAuth 2.0 | User-context queries | Set `clientId` and `clientSecret` |
| Service Account | Automated pipelines | Set path to credentials JSON file |

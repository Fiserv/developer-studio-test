# Getting Started

> Developer Studio Test SDK 2 is an example of file structure and documentation that tenants can use when setting up the documentation for their SDKs. This example is not based on real-world software and is only presented to inform tenants about the SDK functionality now part of the Developer Studio ecosystem.

## Prerequisites

- A DevStudio platform account with an active API key
- Java 17+ or Python 3.10+ installed locally
- Network access to the Query Service endpoint

### Maven

Add the dependency to your `pom.xml`:

```xml
<dependency>
  <groupId>com.devstudio</groupId>
  <artifactId>data-sdk</artifactId>
  <version>3.2.0</version>
</dependency>
```

### Gradle

Add to your `build.gradle`:

```groovy
implementation 'com.devstudio:data-sdk:3.2.0'
```

import com.devstudio.datasdk.DevStudioConfig;

DevStudioConfig config = DevStudioConfig.builder()

**Configuration Options:**

| Parameter | Type | Default | Description |
| --------- | ---- | ------- | ----------- |
| `apiKey` | string | — | Your DevStudio platform API key (required) |
| `environment` | string | `"production"` | Target environment: `sandbox`, `staging`, or `production` |
| `maxConnections` | int | 5 | Maximum number of concurrent connections in the pool |
| `timeoutMs` | int | 30000 | Request timeout in milliseconds |
| `retryAttempts` | int | 3 | Number of automatic retry attempts for transient failures |

## Your First Query

<Tabs defaultValue="java">
  <TabsList>

```java
import com.devstudio.datasdk.DevStudioClient;
import com.devstudio.datasdk.QueryResult;
import com.devstudio.datasdk.Row;

DevStudioClient client = DevStudioClient.create(
    DevStudioConfig.builder().apiKey("your-api-key").build()
);

QueryResult result = client.query(
    "SELECT customer_id, total_spent, last_purchase_date " +
    "FROM transactions " +
    "WHERE total_spent > 1000 " +
    "ORDER BY total_spent DESC " +
    "LIMIT 10"
);

for (Row row : result.getRows()) {
    System.out.printf("Customer %s: $%.2f%n",
        row.getString("customer_id"),
        row.getDouble("total_spent")
    );
}

client.close();
```

  </TabsContent>
  <TabsContent value="python">

```python
from devstudio_data_sdk import DevStudioClient

client = DevStudioClient(api_key="your-api-key")

result = client.query("""
    SELECT customer_id, total_spent, last_purchase_date
    FROM transactions
    WHERE total_spent > 1000
    ORDER BY total_spent DESC
    LIMIT 10
""")

for row in result.rows:
    print(f"Customer {row['customer_id']}: ${row['total_spent']:.2f}")

client.close()
```

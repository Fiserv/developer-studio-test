# Developer Studio Test SDK 1

> The Developer Studio Test SDK 1 provides a simple, secure interface for integrating payment processing into your JavaScript and TypeScript applications.

## Overview

The Developer Studio Test SDK 1 enables developers to accept payments, manage transactions, and handle refunds with minimal configuration. It supports credit cards, digital wallets, and bank transfers out of the box.

## Installation

```bash
npm install @devstudio/payments-sdk
```

Or using Yarn:

```bash
yarn add @devstudio/payments-sdk
```

## Quick Start

```javascript
import { DevStudioPayments } from '@devstudio/payments-sdk';

const client = new DevStudioPayments({
  apiKey: 'your-api-key',
  environment: 'sandbox'
});

const charge = await client.charges.create({
  amount: 2500,
  currency: 'USD',
  source: 'tok_visa_4242',
  description: 'Order #1234'
});

console.log(charge.id); // "ch_9f8a7b6c5d4e"
```
